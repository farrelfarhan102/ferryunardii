# Ferry Unardi – Pendiri Traveloka

Website profil multi-halaman bertema **"Memanfaatkan Teknologi untuk Mempermudah Perjalanan"**.
Dibuat dengan HTML, CSS, dan JavaScript murni (tanpa framework), responsif untuk HP.

## Struktur
```
index.html
css/style.css
js/script.js
assets/ferry-unardi.jpg
```

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub (contoh: `ferry-unardi`), set **Public**.
2. Upload semua file dan folder di atas ke repository.
3. Buka **Settings → Pages**.
4. Pada *Build and deployment*, pilih **Deploy from a branch**, branch **main**, folder **/ (root)**, lalu **Save**.
5. Tunggu 1–2 menit. Website tersedia di `https://USERNAME.github.io/ferry-unardi/`.

## Catatan
- Ganti foto dengan menimpa `assets/ferry-unardi.jpg` (nama sama).
- Cantumkan sumber foto dan verifikasi data lewat sumber resmi sebelum dikutip.
